---
title: Code
---

Code in running text, keys, and code blocks: cream type (`--code-ink`) on nearly black (`--code-bg`), with a
trace of the night's aubergine. The black is partly see-through (72 %), so on the deck's glass and over the
waves a block lets the colours behind it show faintly, while the cream keeps at least 7.8 : 1 even over white.

The elements take the style themselves (`base/typography.scss`): `pre` is a block with a light edge and rounded
corners that scrolls sideways when a line is too long; `code`, `kbd` and `samp` in running text get a small
rounded background that wraps with the line. Code inside a block takes the block's style. The font is
`--font-mono`, a touch smaller than the text around it.

The lower block sits on a band of the deck's colours, to show the transparency.
